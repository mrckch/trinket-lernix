Mit for baust du eine Schleife, die Anweisungen für jedes Element einer Sammlung wiederholt.

Zum Beispiel über eine Liste:

buchstaben = ["a", "b", "c", "d"]
for buchstabe in buchstaben:
    print(buchstabe)

Das klappt mit allem, was man durchlaufen kann, etwa Zeichenketten und Dictionaries:

# alle Zeichen einer Zeichenkette
for zeichen in "Hallo":
    print(zeichen)

# alle Schlüssel eines Dictionaries
zahlen = {'eins': 1, 'zwei': 2, 'drei': 3}
for name in zahlen:
    print(name)
