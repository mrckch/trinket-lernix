Mit def definierst du eine Funktion. Danach folgt der Name der Funktion:

def sag_hallo():
    print("Hallo aus meiner Funktion!")

Funktionen können Parameter entgegennehmen und einen Wert zurückgeben:

def summe(a, b):
    return a + b

Wie ruft man eine Funktion auf?

Einfach den Namen mit runden Klammern schreiben und darin die Argumente übergeben:

# Begrüßung ausgeben
sag_hallo()

# Summe von 1 und 2 ausgeben
print(summe(1, 2))
