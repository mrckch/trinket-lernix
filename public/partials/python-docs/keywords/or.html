Der Operator or liefert True, wenn mindestens eine der beiden Seiten wahr ist. Nur wenn beide falsch sind, kommt False heraus:

AusdruckErgebnis
True or TrueTrue
True or FalseTrue
False or TrueTrue
False or FalseFalse

Ist die erste Seite schon wahr, prüft Python die zweite gar nicht mehr, weil das Ergebnis dann ohnehin feststeht.
