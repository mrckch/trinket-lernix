else wird zusammen mit if benutzt und legt fest, was passiert, wenn die Bedingung falsch ist:

x = 1
if x < 10:
    print("x ist kleiner als zehn")
else:
    print("x ist mindestens zehn")

Hier wird „x ist kleiner als zehn“ ausgegeben. Stünde in der ersten Zeile x = 20, käme stattdessen der else-Block an die Reihe.
