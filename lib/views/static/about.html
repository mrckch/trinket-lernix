Über {{ config.app.siteName }}

{{ config.app.siteName }} ist die Programmierumgebung unserer Schule: Code schreiben und ausführen direkt im Browser, ohne Installation.

Die Anmeldung läuft über IServ. Schülerinnen und Schüler bearbeiten Aufgaben aus dem Unterricht und speichern eigene Projekte, Lehrkräfte legen Kurse für ihre IServ-Gruppen an und sehen den Lernstand im Dashboard.

Was geht

  • Python (Turtle, Konsole), HTML/CSS/JavaScript, Blöcke und Web VPython im Browser
  • Eigene Projekte speichern, teilen und in IServ-Seiten einbetten
  • Kurse mit Seiten und Aufgaben, Abgabe und Rückmeldung
  • Daten bleiben auf dem Schulserver

Open Source
